# Personal Portfolio Website

A portfolio website created to showcase my education, skills, projects, and experiences.

## Installation & Setup

### Prerequisites
- Node.js (version 14.0 or higher)
- npm (comes with Node.js) or yarn package manager
- Git (for cloning the repository)

1. **Clone the repository**
   
   git clone https://github.com/mkerwoodchamp/PortfolioWebsite.git
   
   cd portfolio-website

3. **Install dependencies**

   npm install

4. **Start the development server**

   npm start

5. **Open your browser**
   
   Navigate to `http://localhost:3000` to view the portfolio

## Technologies Used

**Frontend Framework:**
- React 18.2.0

- HTML5
- CSS3

## Features Implemented

### Core Features
- **Responsive Design**: Mobile-first approach that works seamlessly across all device sizes
- **Dark/Light Mode Toggle**: User-controlled theme switching with smooth transitions
- **Smooth Scrolling Navigation**: Fixed navigation bar with active section highlighting
- **Component-Based Architecture**: Modular React components for maintainability

### Interactive Elements
- **Animated Hero Section**: Eye-catching landing with gradient text and call-to-action buttons
- **Hover Effects**: Interactive project cards and navigation elements
- **Mobile Menu**: Collapsible navigation for mobile devices
- **Progress Indicators**: Visual feedback for user interactions

### Content Sections
- **Hero Section**: Personal introduction with professional tagline
- **About Section**: Academic journey and personal background
- **Skills Section**: Technical skills organized by category with badge-style display
- **Projects Section**: Featured projects with descriptions, tech stacks, and links
- **Education Section**: Comprehensive academic information including coursework and achievements
- **Contact Section**: Professional contact information and social media links
- **Footer**: Copyright and additional information

### Technical Features
- **Optimized Performance**: Efficient re-rendering and smooth animations
- **Accessibility**: Proper semantic HTML and keyboard navigation
- **Cross-Browser Compatibility**: Works on all modern browsers
- **SEO-Friendly**: Proper document structure and meta information

## Known Issues or Limitations

### Current Limitations
- **Image Dependencies**: Local images require proper asset management in the build process
- **Static Content**: All content is hardcoded in JavaScript objects
- **Single Language**: Currently only supports English content
- **Limited Analytics**: No built-in visitor tracking or performance analytics

### Browser Compatibility
- **Internet Explorer**: Not supported (requires modern ES6+ features)
- **Older Mobile Browsers**: Some CSS features may not work on very old mobile browsers
